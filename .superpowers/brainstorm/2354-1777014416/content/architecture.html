项目结构

mass-concrete-app/                    # Tauri 应用（主项目）
├── src/                             # React 前端
│   ├── components/                  # 公共组件
│   ├── pages/                       # 页面组件
│   │   ├── MixDesign/              # 配合比设计
│   │   ├── TempRise/              # 温升计算
│   │   ├── Stress/                # 应力计算
│   │   ├── Insulation/             # 保温计算
│   │   └── History/                # 历史记录
│   ├── store/                       # Redux 状态管理
│   └── services/                   # 前端服务（调用 Tauri Commands）
├── src-tauri/                       # Rust 后端
│   ├── src/
│   │   ├── commands/              # Tauri 命令处理器
│   │   ├── db/                    # 数据库访问层
│   │   └── main.rs
│   └── Cargo.toml
└── mass-concrete-calc/              # 独立 Rust 计算库
    ├── src/
    │   ├── adiabatic_temp.rs      # 温升计算
    │   ├── stress.rs              # 应力计算
    │   ├── insulation.rs          # 保温计算
    │   └── lib.rs
    └── Cargo.toml

技术栈总结

桌面框架 Tauri 2.x
前端框架 React 18+
状态管理 Redux Toolkit
数据库 SQLite (通过 Rust rusqlite)
计算逻辑 独立 Rust crate (mass-concrete-calc)
构建工具 Vite
