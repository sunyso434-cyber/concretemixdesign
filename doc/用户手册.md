# 混凝土配合比设计软件用户手册

## 1. 系统概述

混凝土配合比设计软件是一款基于 Electron + React + SQLite 开发的桌面应用程序，用于混凝土配合比的设计、计算和管理。系统支持原材料管理、配合比设计、方案管理、系统设置等功能，依据 JGJ 55、GB 50010-2010、GB 50204-2015、JGJ/T 193-2009 等标准进行配合比计算。

### 1.1 系统特点

- **现代化界面**：采用现代扁平化设计风格，操作简单直观
- **功能完备**：支持原材料管理、配合比设计、方案管理、系统设置等功能
- **数据安全**：支持数据库备份和恢复，确保数据安全
- **数据导入/导出**：支持 Excel 和 PDF 格式的数据导入/导出
- **多标准支持**：依据多个国家标准进行配合比计算
- **预设材料**：内置常用原材料，支持自定义材料

## 2. 安装指南

### 2.1 系统要求

- **操作系统**：Windows 7 及以上，macOS 10.10 及以上，Linux
- **处理器**：Intel Core i3 及以上
- **内存**：4GB 及以上
- **存储空间**：200MB 及以上

### 2.2 安装步骤

1. **下载安装包**：从官方网站或指定渠道下载安装包
2. **运行安装程序**：双击安装包，按照提示完成安装
3. **启动系统**：安装完成后，点击桌面快捷方式启动系统

### 2.3 卸载步骤

1. **Windows**：在控制面板中选择 "程序和功能"，找到 "混凝土配合比设计软件"，点击 "卸载"
2. **macOS**：将应用程序拖到废纸篓
3. **Linux**：使用包管理器卸载或删除安装目录

## 3. 使用说明

### 3.1 登录系统

启动系统后，无需登录即可使用所有功能。

### 3.2 主界面

主界面包含以下部分：

- **左侧导航栏**：包含原材料管理、配合比设计、方案管理、系统设置等功能入口
- **右侧内容区**：显示当前功能的详细内容
- **顶部状态栏**：显示系统版本信息和操作按钮

### 3.3 原材料管理

#### 3.3.1 功能介绍

原材料管理模块用于管理混凝土配合比所需的各种原材料，包括水泥、粉煤灰、矿渣粉、细骨料、粗骨料、外加剂等。

#### 3.3.2 操作步骤

1. **添加原材料**：点击 "添加材料" 按钮，填写材料信息，点击 "保存" 按钮
2. **编辑原材料**：点击原材料列表中的 "编辑" 按钮，修改材料信息，点击 "保存" 按钮
3. **删除原材料**：点击原材料列表中的 "删除" 按钮，确认删除
4. **查看原材料详情**：点击原材料列表中的 "详情" 按钮，查看材料详细信息
5. **输出试验报告**：点击原材料列表中的 "试验报告" 按钮，生成并下载试验报告

### 3.4 配合比设计

#### 3.4.1 功能介绍

配合比设计模块用于根据原材料性能和设计要求，计算混凝土配合比。

#### 3.4.2 操作步骤

1. **选择设计参数**：选择混凝土强度等级、坍落度、环境类别等参数
2. **选择原材料**：从下拉菜单中选择所需的原材料
3. **计算配合比**：点击 "计算配合比" 按钮，系统根据所选参数和原材料性能计算配合比
4. **验证配合比**：系统自动验证计算结果是否符合标准要求
5. **优化配合比**：根据需要调整配合比参数，点击 "优化配合比" 按钮
6. **保存方案**：点击 "保存方案" 按钮，将当前配合比保存为方案

### 3.5 方案管理

#### 3.5.1 功能介绍

方案管理模块用于管理已保存的配合比方案，支持方案的查看、编辑、复制、删除等操作。

#### 3.5.2 操作步骤

1. **查看方案列表**：系统显示所有已保存的配合比方案
2. **查看方案详情**：点击方案列表中的 "详情" 按钮，查看方案详细信息
3. **编辑方案**：点击方案列表中的 "编辑" 按钮，修改方案信息，点击 "保存" 按钮
4. **复制方案**：点击方案列表中的 "复制" 按钮，创建方案副本
5. **删除方案**：点击方案列表中的 "删除" 按钮，确认删除
6. **导出方案**：点击方案列表中的 "导出" 按钮，导出方案为 Excel 或 PDF 格式

### 3.6 系统设置

#### 3.6.1 功能介绍

系统设置模块用于管理系统参数、数据库备份和恢复、数据导入/导出等功能。

#### 3.6.2 操作步骤

1. **系统参数设置**：
   - 点击 "添加参数" 按钮，添加新的系统参数
   - 点击参数列表中的 "编辑" 按钮，修改参数值
   - 点击参数列表中的 "删除" 按钮，删除参数

2. **数据管理**：
   - **备份数据库**：点击 "备份数据库" 按钮，系统自动备份数据库
   - **恢复数据库**：点击 "恢复数据库" 按钮，选择备份文件进行恢复
   - **导入数据**：点击 "导入数据" 按钮，选择数据文件进行导入
   - **导出数据**：点击 "导出数据" 按钮，选择导出路径和格式

3. **关于系统**：
   - 查看系统版本信息和开发技术栈

## 4. 功能详解

### 4.1 原材料管理

#### 4.1.1 原材料类型

系统支持以下原材料类型：

- **水泥**：普通硅酸盐水泥、矿渣硅酸盐水泥、火山灰质硅酸盐水泥等
- **粉煤灰**：Ⅰ级、Ⅱ级、Ⅲ级粉煤灰
- **矿渣粉**：S95、S105 级矿渣粉
- **细骨料**：天然砂、人工砂
- **粗骨料**：碎石、卵石
- **外加剂**：减水剂、缓凝剂、早强剂等

#### 4.1.2 原材料属性

每种原材料包含以下属性：

- **基本信息**：名称、类型、规格、生产厂家、进场日期等
- **性能指标**：根据原材料类型不同，包含不同的性能指标
  - 水泥：强度等级、安定性、凝结时间等
  - 粉煤灰：细度、需水量比、烧失量等
  - 矿渣粉：比表面积、活性指数等
  - 细骨料：细度模数、含泥量、泥块含量等
  - 粗骨料：颗粒级配、压碎指标、针片状含量等
  - 外加剂：减水率、坍落度保持能力等

### 4.2 配合比设计

#### 4.2.1 设计参数

配合比设计需要以下参数：

- **混凝土强度等级**：C15、C20、C25、C30、C35、C40、C45、C50 等
- **坍落度**：根据施工要求选择，通常为 10-200mm
- **环境类别**：根据 GB 50010-2010 标准选择，分为 1-5 类
- **设计龄期**：通常为 28 天
- **容重**：通常为 2400kg/m³

#### 4.2.2 计算方法

系统根据 JGJ 55 标准进行配合比计算，主要步骤包括：

1. **计算配制强度**：根据混凝土强度等级和标准差计算
2. **确定水胶比**：根据配制强度和水泥强度等级确定
3. **确定用水量**：根据坍落度和粗骨料品种、规格确定
4. **计算胶凝材料用量**：根据水胶比和用水量计算
5. **确定砂率**：根据粗骨料品种、规格和水胶比确定
6. **计算砂、石用量**：根据胶凝材料用量、用水量、砂率和容重计算
7. **验证配合比**：验证计算结果是否符合标准要求
8. **优化配合比**：根据需要调整配合比参数

### 4.3 方案管理

#### 4.3.1 方案属性

每个配合比方案包含以下属性：

- **基本信息**：方案名称、创建日期、修改日期、创建人等
- **设计参数**：混凝土强度等级、坍落度、环境类别等
- **原材料用量**：各种原材料的用量（kg/m³）
- **配合比性能**：计算出的配合比性能指标

#### 4.3.2 方案操作

系统支持以下方案操作：

- **查看**：查看方案详细信息
- **编辑**：修改方案参数和原材料用量
- **复制**：创建方案副本，方便快速修改
- **删除**：删除不需要的方案
- **导出**：导出方案为 Excel 或 PDF 格式

### 4.4 系统设置

#### 4.4.1 系统参数

系统参数包括：

- **系统参数**：默认语言、默认单位制等
- **配合比参数**：默认强度等级、默认坍落度、默认环境类别、默认容重等
- **备份参数**：自动备份、备份间隔等

#### 4.4.2 数据管理

数据管理功能包括：

- **数据库备份**：将数据库备份到指定位置
- **数据库恢复**：从备份文件恢复数据库
- **数据导入**：导入外部数据到系统
- **数据导出**：将系统数据导出为外部文件

## 5. 常见问题与解决方案

### 5.1 安装问题

**问题**：安装失败
**解决方案**：检查系统是否满足最低要求，关闭其他应用程序后重新安装

**问题**：启动失败
**解决方案**：检查是否安装了所有必要的依赖，尝试重新安装

### 5.2 功能问题

**问题**：原材料添加失败
**解决方案**：检查填写的信息是否完整，确保所有必填字段都已填写

**问题**：配合比计算失败
**解决方案**：检查选择的原材料是否完整，参数设置是否合理

**问题**：方案保存失败
**解决方案**：检查方案名称是否已存在，确保所有必填字段都已填写

### 5.3 数据问题

**问题**：数据丢失
**解决方案**：使用系统备份功能恢复数据库

**问题**：数据导入失败
**解决方案**：检查导入文件格式是否正确，确保文件内容符合系统要求
