# 混凝土配合比设计软件用户手册

## 1. 系统概述

混凝土配合比设计软件是一款基于 Electron + React + SQLite 开发的桌面应用程序，用于混凝土配合比的设计、计算和管理。系统支持原材料管理、配合比设计、成本优化、方案管理、数据导入导出等功能，依据 JGJ 55-2011、GB 50010-2010、GB 50204-2015、JGJ/T 193-2009 等标准进行配合比计算。

### 1.1 系统特点

- **现代化界面**：采用现代扁平化设计风格，操作简单直观
- **功能完备**：支持原材料管理、配合比设计、成本优化、方案管理、系统设置等功能
- **数据安全**：支持数据库备份和恢复，确保数据安全
- **数据导入/导出**：支持 Excel 多 Sheet 格式的数据导入导出
- **多标准支持**：依据多个国家标准进行配合比计算
- **成本优化**：支持智能网格搜索优化，寻找最低成本配合比方案
- **批量计算**：支持 C15-C60 系列配合比一次性批量计算

## 2. 安装指南

### 2.1 系统要求

- **操作系统**：Windows 10 及以上（64位）
- **处理器**：Intel Core i3 及以上
- **内存**：4GB 及以上
- **存储空间**：500MB 及以上

### 2.2 安装步骤

1. **下载安装包**：从官方网站或指定渠道下载安装包
2. **运行安装程序**：双击安装包，按照提示完成安装
3. **启动系统**：安装完成后，点击桌面快捷方式启动系统

### 2.3 卸载步骤

1. **Windows**：在控制面板中选择 "程序和功能"，找到 "混凝土配合比设计系统"，点击 "卸载"

## 3. 界面介绍

### 3.1 主界面布局

主界面包含以下部分：

- **顶部导航栏**：包含原材料管理、配合比设计、成本优化、方案管理、系统管理等功能入口
- **中部内容区**：显示当前功能的详细内容
- **底部状态栏**：显示后台任务进度（如有优化任务进行中）

| 原材料管理 | 管理混凝土配合比所需的各种原材料信息 |

| 成本优化 | 智能寻找满足约束条件的最低成本配合比方案 |

## 4. 原材料管理

### 4.1 功能介绍

原材料管理模块用于管理混凝土配合比所需的各种原材料，包括水泥、粉煤灰、矿渣粉、细骨料、粗骨料、外加剂等。

### 4.2 材料类型

系统支持以下原材料类型：

| 材料类型 | 说明 | 关键参数 |
|----------|------|----------|
| 水泥 | 普通硅酸盐水泥等 | 强度等级、密度、价格 |
| 粉煤灰 | Ⅰ级、Ⅱ级、Ⅲ级粉煤灰 | 细度、需水量比、烧失量、价格 |
| 矿渣粉 | S95、S105 级矿渣粉 | 比表面积、活性指数、价格 |
| 细骨料 | 天然砂、人工砂 | 细度模数、含泥量、泥块含量、级配筛分、价格 |
| 粗骨料 | 碎石、卵石 | 粒径、压碎指标、针片状含量、级配筛分、价格 |
| 减水剂 | 普通减水剂、高效减水剂等 | 减水率、泌水率比、价格 |
| 其他 | 其他材料 | 自定义参数 |

### 4.3 操作步骤

1. **查看材料列表**：在原材料管理页面查看所有已添加的材料信息
2. **添加材料**：点击 "新增材料" 按钮，选择材料类型，填写材料信息，点击 "确定" 保存
3. **编辑材料**：点击材料列表中的 "编辑" 按钮，修改材料信息，点击 "确定" 保存
4. **删除材料**：点击材料列表中的 "删除" 按钮，确认删除
5. **刷新列表**：点击 "刷新" 按钮重新加载材料列表

### 4.4 材料表单字段

根据材料类型不同，表单字段分为通用字段和类型特定字段：

**通用字段（所有材料）**：
- 材料名称（必填）
- 材料类型（必填）
- 规格
- 生产厂家
- 单价（元/吨）（必填）
- 密度（kg/m³）

**类型特定字段**：
- 细骨料：细度模数（自动计算）、各粒径筛余等
- 粗骨料：级配、压碎指标、针片状含量等
- 粉煤灰：细度、需水量比、烧失量
- 矿渣粉：比表面积、活性指数
- 减水剂：减水率、坍落度保持能力

## 5. 配合比设计

### 5.1 功能介绍

配合比设计模块用于根据原材料性能和设计要求，计算混凝土配合比。支持单个计算和批量系列计算。

### 5.2 设计参数

配合比设计需要设置以下参数：

**性能目标参数**：
- 强度等级：C15、C20、C25、C30、C35、C40、C45、C50、C55、C60
- 坍落度（mm）：根据施工要求指定
- 环境类别：一类（室内干燥）、二类 a（室内潮湿）、二类 b（露天）、三类 a（除冰盐）、三类 b（海水）
- 工程类型：民用建筑、工业建筑、桥梁工程、水利工程

**材料配比参数**：
- 粉煤灰掺量（%）
- 矿渣粉掺量（%）
- 砂率（%）

### 5.3 操作步骤

#### 5.3.1 单个配合比计算

1. **设置设计目标参数**：选择强度等级、坍落度、环境类别、工程类型
2. **设置材料配比**：输入粉煤灰掺量、矿渣粉掺量、砂率
3. **选择原材料**：从下拉菜单中选择水泥、粉煤灰、矿渣粉、细骨料、粗骨料、外加剂
   - 细骨料和粗骨料支持多选，系统会自动优化多种骨料的掺配比例
4. **计算配合比**：点击 "计算配合比" 按钮，系统计算配合比
5. **查看结果**：计算结果以表格形式展示，包括各材料用量、配合比参数、成本分析
6. **保存方案**：点击 "保存方案" 按钮，输入方案名称保存

#### 5.3.2 系列配合比计算

1. 完成上述步骤 1-3
2. 点击 "计算系列配合比" 按钮
3. 系统自动计算 C15-C60 所有强度等级的配合比
4. 在页面下方以表格形式展示所有强度等级的配合比对比

#### 5.3.3 高级设置

点击 "高级设置" 按钮可配置以下高级参数：

- **回归系数 α_a**：默认 0.53，范围 0.4-0.6
- **回归系数 α_b**：默认 0.20，范围 0.1-0.3
- **强度标准差 σ(MPa)**：留空使用默认值
- **减水剂掺量影响参数**：MB值影响、细度模数影响、强度等级影响
- **细骨料参数**：C30 基准目标细度模数

### 5.4 计算结果

计算完成后显示以下信息：

**材料用量表**：
| 材料 | 用量 | 单位 |
|------|------|------|
| 水泥 | xxx | kg/m³ |
| 粉煤灰 | xxx | kg/m³ |
| 矿渣粉 | xxx | kg/m³ |
| 砂 | xxx | kg/m³ |
| 石 | xxx | kg/m³ |
| 水 | xxx | kg/m³ |
| 减水剂 | xxx | kg/m³ |

**配合比参数**：
- 配置强度 f_cu,0
- 水胶比
- 砂率
- 容重
- 减水剂掺量
- 减水率

**成本分析**：
- 各材料成本明细
- 总成本（元/m³）

## 6. 成本优化

### 6.1 功能介绍

成本优化模块通过智能网格搜索算法，在满足所有约束条件的前提下，自动寻找成本最低的配合比方案。

### 6.2 约束条件

**一类约束（性能目标）**：
- 项目名称
- 强度等级
- 坍落度
- 环境类别
- 原材料选择（水泥必选，细骨料、粗骨料、减水剂必选，粉煤灰和矿渣粉可选）

**二类约束（自定义限值）**：
- 粉煤灰掺量范围
- 矿渣粉掺量范围
- 砂率范围
- 网格搜索精度

### 6.3 操作步骤

1. **设置性能目标**：选择项目名称、强度等级、坍落度、环境类别
2. **选择原材料**：
   - 水泥（单选，必填）
   - 粉煤灰（多选，可选）
   - 矿渣粉（多选，可选）
   - 细骨料（多选，可优化掺配比例）
   - 粗骨料（多选）
   - 减水剂（多选）
3. **设置约束限值**：配置各参数的搜索范围和网格精度
4. **开始优化**：点击 "开始优化" 按钮
5. **查看结果**：优化完成后显示最优方案，包括最优配合比、成本分析
6. **保存方案**：点击 "保存最优方案" 按钮保存

### 6.4 优化结果

优化完成后显示：
- 最优方案的总成本（元/m³）
- 水胶比和砂率
- 表观密度
- 各材料最优用量
- 各材料成本明细

## 7. 方案管理

### 7.1 功能介绍

方案管理模块用于管理已保存的配合比方案，支持查看、编辑、复制、删除、对比等操作。

### 7.2 操作步骤

1. **查看方案列表**：在方案管理页面查看所有已保存的配合比方案
2. **查看方案详情**：点击方案列表中的 "查看" 按钮，查看方案详细信息
3. **编辑方案**：点击 "编辑" 按钮，修改方案信息
4. **复制方案**：点击 "复制" 按钮，创建方案副本
5. **删除方案**：点击 "删除" 按钮，确认删除
6. **导出方案**：点击 "导出" 按钮（功能开发中）
7. **对比方案**：选择多个方案，点击 "对比选中方案" 按钮进行对比分析

### 7.3 方案详情内容

方案详情包括：
- 基本信息：方案名称、项目名称、强度等级、坍落度、环境类别、状态
- 材料用量：各种材料的用量（kg/m³）
- 配合比参数：水胶比、砂率、容重
- 成本信息：各材料成本明细和总成本
- 原材料信息：所用原材料的名称、规格、单价、厂家

## 8. 系统管理

### 8.1 功能介绍

系统管理模块用于管理系统参数、数据库备份恢复、数据导入导出等功能。

### 8.2 参数设置

系统提供四类参数配置：

**配合比参数**：
- 默认强度等级
- 默认坍落度
- 默认砂率
- 默认容重

**JGJ55 标准参数**：
- 回归系数 α_a
- 回归系数 α_b
- 强度标准差
- 粉煤灰影响参数
- 矿渣粉影响参数

**系统设置**：
- 系统语言
- 数据精度

**备份设置**：
- 自动备份开关
- 备份间隔

### 8.3 数据管理

#### 8.3.1 备份数据库

1. 点击 "备份数据库" 按钮
2. 在弹出的对话框中选择备份文件保存位置
3. 点击 "保存" 开始备份

#### 8.3.2 恢复数据库

1. 点击 "恢复数据库" 按钮
2. 选择备份文件
3. 确认恢复操作（此操作会覆盖现有数据）

#### 8.3.3 导出数据

1. 点击 "导出数据" 按钮
2. 选择要导出的数据类型（可多选）：
   - 原材料库
   - 配合比方案
   - 系统参数
3. 选择导出格式：Excel (.xlsx)、CSV (.csv)、JSON (.json)
4. 点击 "导出" 按钮
5. 选择保存位置

#### 8.3.4 导入数据

1. 点击 "导入数据" 按钮
2. 选择导入数据类型：原材料 或 配合比方案
3. 下载导入模板
4. 按模板格式填写数据
5. 上传填写好的文件
6. 预览数据确认
7. 点击 "确认导入"

**导入模板说明**：
- 原材料导入模板包含 7 个 Sheet（水泥、粉煤灰、矿渣粉、细骨料、粗骨料、外加剂、其他），按类别填写
- 配合比导入模板包含配合比主数据 Sheet 和关联明细 Sheet
- 请勿修改表头格式

## 9. 常见问题

### 9.1 功能问题

**问题**：配合比计算失败
**解决方案**：检查选择的原材料是否完整，参数设置是否合理

**问题**：成本优化找不到满足条件的方案
**解决方案**：请放宽约束条件（如增大粉煤灰、矿渣粉掺量范围）或更换原材料

**问题**：数据导入失败
**解决方案**：检查导入文件格式是否正确，确保所有必填字段都已填写

### 9.2 数据问题

**问题**：数据丢失
**解决方案**：使用系统备份功能从备份文件恢复数据库

**问题**：导入模板在哪里下载
**解决方案**：在系统管理的导入数据功能中，点击下载模板按钮
