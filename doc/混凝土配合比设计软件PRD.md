# 混凝土配合比设计软件产品需求文档

## 1. 产品概览

混凝土配合比设计软件是一款专为建筑工程领域设计的专业工具，用于帮助工程技术人员高效、准确地进行混凝土配合比设计、计算和成本优化。

该产品旨在解决传统配合比设计过程中计算复杂、数据管理混乱、方案复用性差、成本优化困难等问题，通过系统化的原材料管理、智能化的配合比计算、规范化的方案管理和自动化的成本优化，提高设计效率，确保混凝土质量，降低工程成本。

产品的目标是成为工程技术人员的必备工具，为混凝土配合比设计提供全面的解决方案，适用于各类建筑工程、水利工程、交通工程等领域。

## 2. 核心功能

### 2.1 功能模块

混凝土配合比设计软件包含以下主要功能模块：

| 模块名称 | 功能描述 |
|----------|----------|
| 原材料管理 | 管理水泥、粉煤灰、矿渣粉、细骨料、粗骨料、外加剂等原材料信息 |
| 配合比设计 | 根据 JGJ 55-2011 标准计算混凝土配合比，支持单个和批量计算 |
| 成本优化 | 通过网格搜索算法寻找满足约束条件的最低成本配合比方案 |
| 方案管理 | 保存、管理、复用配合比设计方案 |
| 系统管理 | 配置系统参数、数据备份恢复、数据导入导出 |

### 2.2 页面架构

```
├── 原材料管理页面 (MaterialsPage)

│   ├── 原材料选择（支持多选细骨料/粗骨料）
│   ├── 单个配合比计算
│   ├── 系列配合比计算（C15-C60 批量）
│   ├── 高级设置（回归系数、减水剂参数等）
│   ├── 计算结果展示
│   ├── 成本分析
│   └── 保存方案
│
├── 成本优化页面 (OptimizationPage)
│   ├── 性能目标约束
│   ├── 原材料选择（支持多选）
│   ├── 自定义约束限值
│   ├── 网格搜索优化
│   ├── 优化进度展示
│   ├── 最优方案展示
│   └── 保存最优方案
│
├── 方案管理页面 (SchemesPage)
│   ├── 方案列表（表格、分页、筛选）
│   ├── 查看方案详情
│   ├── 编辑方案信息
│   ├── 复制方案
│   ├── 删除方案
│   ├── 导出方案
│   └── 方案对比分析
│
└── 系统管理页面 (SettingsPage)
    ├── 参数设置（配合比参数、JGJ55标准、系统设置、备份设置）
    ├── 数据库备份
    ├── 数据库恢复
    ├── 数据导出（多格式）
    └── 数据导入（多 Sheet Excel 模板）
```

## 3. 详细功能需求

## 4. 技术架构

### 4.1 技术栈

- **前端框架**：React 18 + React Router
- **UI 组件库**：Ant Design 5
- **状态管理**：Redux Toolkit
- **桌面框架**：Electron
- **数据库**：SQLite (better-sqlite3)
- **Excel 处理**：xlsx (SheetJS)
- **构建工具**：Vite

### 4.2 数据模型

**原材料 (Material)**：
```
id, name, type, specification, manufacturer, price, density,
[类型特定字段...]
createdAt, updatedAt
```

**配合比方案 (MixDesign)**：
```
id, name, projectName, strength, slump, environment,
waterRatio, sandRatio, density, totalCost,
materials (JSON), materialCosts (JSON), materialDetails (JSON),
fineAggregateBreakdown (JSON), coarseAggregateBreakdown (JSON),
status, description, tempSettings (JSON),
createdAt, updatedAt
```

**系统参数 (SystemParam)**：
```
id, name, value, type, description
```

### 4.3 配合比计算标准依据

- JGJ 55-2011《普通混凝土配合比设计规程》
- GB 50010-2010《混凝土结构设计规范》
- GB 50204-2015《混凝土结构工程施工质量验收规范》
- JGJ/T 193-2009《混凝土耐久性检验评定标准》

## 5. 用户流程

### 5.1 原材料管理流程

```
1. 进入原材料管理页面
2. 点击"新增材料"
3. 选择材料类型
4. 填写材料信息（名称、规格、厂家、价格等）
5. 填写类型特定参数
6. 点击"确定"保存
7. 材料出现在列表中
```

### 5.2 配合比设计流程

```
1. 进入配合比设计页面
2. 设置设计目标参数（强度等级、坍落度等）
3. 设置材料配比参数（粉煤灰、矿渣粉、砂率）
4. 从材料库选择原材料
5. 点击"计算配合比"
6. 查看计算结果和成本分析
7. （可选）点击"高级设置"调整参数
8. （可选）点击"计算系列配合比"批量计算
9. 点击"保存方案"
10. 输入方案名称和项目信息
11. 确认保存
```

### 5.3 成本优化流程

```
1. 进入成本优化页面
2. 设置性能目标约束（强度等级、坍落度、环境类别）
3. 选择原材料（水泥必选，其他可选多选）
4. 设置自定义约束范围（粉煤灰、矿渣粉、砂率）
5. 设置网格搜索精度
6. 点击"开始优化"
7. 等待优化完成（可切换到其他页面）
8. 查看最优方案和成本
9. 点击"保存最优方案"
```

### 5.4 数据导入流程

```
1. 进入系统管理页面
2. 点击"导入数据"
3. 选择导入数据类型（原材料/配合比方案）
4. 点击"下载模板"
5. 按模板格式填写数据
6. 返回导入向导，上传填写好的文件
7. 预览数据
8. 确认导入
```
