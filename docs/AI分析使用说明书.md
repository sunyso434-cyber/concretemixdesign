# AI配合比分析 使用说明书

## 一、功能概述

AI配合比分析模块提供两大核心功能：

| 功能 | 入口 | 适用场景 |
|------|------|----------|
| **智能解析** | AI分析 → 智能解析 | 批量数据分析、生成分析报告 |
| **智能设计** | AI分析 → 智能设计 | 对话式咨询、材料选择、成本优化 |

---

## 二、前置要求

### 2.1 配置API密钥

使用AI功能前，必须先配置DeepSeek API密钥：

1. 进入 **系统设置** 页面
2. 找到 `deepseekApiKey` 配置项
3. 填入您的DeepSeek API密钥
4. 保存设置

> **注意**：API密钥是调用DeepSeek云端服务的凭证，如未配置或配置错误，AI功能将无法使用。

## 三、智能解析使用流程

智能解析适合对批量配合比数据进行系统性分析。

### 3.1 流程总览

```
数据导入 → 数据列表 → 数据处理 → 分析报告
```

### 3.2 第一步：数据导入

**支持的数据格式**：
- Excel文件（.xlsx、.xls）
- 包含配合比数据的标准格式文件

**导入方式**：
1. 点击「上传文件」按钮
2. 选择Excel文件
3. 系统自动解析数据并显示预览

**数据对应关系**：
导入时需要为每个字段指定对应的材料类型：

| Excel字段 | 材料类型 |
|-----------|----------|
| cement | 水泥 |
| flyAsh | 粉煤灰 |
| slag | 矿渣粉 |
| lithiumSlag | 锂渣 |
| compositePowder | 复合粉 |
| fineAggregate1 / fineAggregate2 | 细骨料 |
| coarseAggregate | 粗骨料 |
| waterReducer | 减水剂 |

**材料匹配**：
- 系统会根据材料名称自动匹配材料库
- 也可手动修正材料对应关系
- 只有成功匹配的材料的完整参数才会传给AI分析

### 3.3 第二步：数据列表

- 查看已导入的全部配合比数据
- 可对数据进行修改、删除
- 确认数据无误后进入下一步

### 3.4 第三步：数据处理

**分析选项**：

| 选项 | 说明 |
|------|------|
| 材料性能影响分析 | 分析不同材料对混凝土性能的影响 |
| 配合比参数影响分析 | 分析水胶比、胶材用量等参数的影响 |
| 最优配合比设计 | 基于数据预测最优配合比方案 |
| 参数调整建议 | 识别问题并给出调整建议 |
| 进一步试验建议 | 设计验证性和探索性试验方案 |

**自定义提示词**：
- 可填写「试验目的」，AI会针对性地进行分析
- 例如："验证粉煤灰掺量对混凝土后期强度的影响"

**处理后数据预览**：
- 系统将数据格式化为标准格式
- 可查看上传给AI的完整数据内容

### 3.5 第四步：分析报告

点击「开始分析」按钮，AI将生成完整的分析报告，包含：

1. **材料性能影响分析**
   - 按强度等级分组
   - 材料差异分析或配合比参数差异分析
   - 量化各材料参数对性能的影响程度

2. **配合比参数影响分析**
   - 单参数量化分析
   - 参数影响程度排序
   - 跨强度等级归纳

3. **最优配合比设计**
   - 预测配制强度
   - 预测配合比参数
   - 与现有配合比对比
   - 可行性说明

4. **参数调整建议**
   - 问题识别（严重/一般）
   - 问题归因
   - 调整方案和预期效果

5. **进一步试验建议**
   - 验证性试验
   - 探索性试验
   - 试验矩阵
   - 优先级与资源建议

## 四、智能设计使用流程

智能设计是对话式交互，适合日常咨询和即时问题解答。

### 4.1 交互模式

```
用户 → AI（可调用工具）→ 返回结果
```

### 4.2 可用工具

| 工具 | 用途 | 触发场景 |
|------|------|----------|
| `list_available_materials` | 查询材料库 | 材料选择前 |
| `calculate_mix_design` | 计算配合比 | 提供完整参数后 |
| `optimize_mix_cost` | 成本优化 | 寻找最低成本方案 |

### 4.3 典型对话流程

**场景1：设计新配合比**
```
用户：我想设计一个C30的配合比，坍落度180mm
AI：好的，我来帮您设计C30配合比。首先让我查询一下材料库中有哪些可选材料...
AI：[列出材料表格]
用户：用第一个水泥和砂子
AI：好的，您选择了[水泥名称]和[砂子名称]。请问碎石用什么？减水剂用什么？
用户：碎石用5-10mm的，减水剂用标准型的
AI：好的，现在参数齐全，我来计算配合比...
AI：[返回计算结果，包含各材料用量、成本等]
```

**场景2：成本优化**
```
用户：能不能帮我找一个成本更低的C30方案？
AI：好的，我来帮您优化成本。我将查询材料库，然后对各种组合进行网格搜索...
AI：[返回最优方案及备选方案]
```

**场景3：材料对比**
```
用户：P·O 42.5和P·O 42.5R用在这个配合比里具体差多少？
AI：好的，我来对比这两种水泥的效果差异...
AI：[返回对比表格，包含强度、成本、水胶比等指标差异]
```

### 4.4 注意事项

1. **参数确认**：缺少必填参数时，AI会追问，不会自行填充默认值
2. **材料选择**：第一次配合比设计时，AI会先查询材料库供您选择
3. **对话历史**：可清空对话重新开始

## 五、各工具详细说明

### 5.1 list_available_materials（查询材料库）

**功能**：查询系统中可用的原材料

**参数**：
| 参数 | 类型 | 说明 |
|------|------|------|
| type | string | 材料类型筛选，可选：水泥/细骨料/粗骨料/粉煤灰/矿渣粉/锂渣/复合粉/减水剂 |

**输出**：材料列表（名称、厂商、价格、推荐标识等）

---

### 5.2 calculate_mix_design（计算配合比）

**功能**：根据给定参数计算混凝土配合比

**必填参数**：
| 参数 | 说明 |
|------|------|
| strength | 强度等级，如 C30、C40 |
| slump | 坍落度(mm)，如 180 |
| cementId | 水泥材料ID |
| sandIds | 细骨料ID列表(1-2种) |
| stoneIds | 粗骨料ID列表(1-2种) |

**可选参数**：
| 参数 | 说明 |
|------|------|
| flyAshId / slagId / lithiumSlagId / compositePowderId | 掺合料ID |
| superplasticizerId | 减水剂ID |
| flyAshDosage / slagDosage / ... | 各掺合料掺量(%) |
| sandRatio | 砂率(%)，不填则自动计算 |
| calculationMethod | 计算方法：absolute(绝对体积法)/mass(质量法) |
| targetDensity | 目标容重(kg/m³)，仅质量法使用 |
| tempSettings | 温度参数覆盖 |

**输出**：各材料用量、水胶比、砂率、容重、成本、计算步骤

---

### 5.3 optimize_mix_cost（成本优化）

**功能**：网格搜索找出成本最低的配合比

**输入特点**：
- 接收候选材料ID列表（如多种水泥、多种砂子）
- 在给定范围内遍历掺量组合
- 寻找成本最低且满足强度要求的方案

**输出**：
- 最优方案（材料组合、掺量、成本）
- 若干备选方案
- 总计算量统计

---

### 5.4 compare_materials（材料对比）⚠️ v10.5.0 移除

~~**功能**：控制变量法对比不同材料的效果~~

> v10.5.0 起移除该独立工具。如需对比材料，可让 Agent 循环调用 `calculate_mix_design`，每次替换材料即可。

---

**功能**：控制变量法对比不同材料的效果

**算法原理**：
- 固定配合比参数（强度、坍落度、掺量等）
- 逐一用候选材料替换计算
- 汇总各候选材料的强度、成本、水胶比等指标

**场景示例**：
- 对比3种水泥在相同配合比下的表现
- 对比4种减水剂的效果差异

## 六、常见问题

### Q1：AI分析需要多长时间？
A：普通分析通常10-30秒，复杂优化（网格搜索）可能需要1-3分钟。

### Q2：分析失败怎么办？
A：常见原因：
- API密钥未配置或无效 → 检查系统设置
- 网络连接失败 → 检查网络
- 数据量过大 → 减少配合比数量后重试
- 请求频率超限 → 稍后重试

### Q3：如何获得更准确的分析结果？
A：
- 填写「试验目的」，AI会针对性地分析
- 确保材料参数完整（尤其是价格）
- 配合比数量建议5-30组效果最佳

### Q4：智能设计和智能解析有什么区别？
A：
- 智能解析：批量数据分析，一次性生成完整报告
- 智能设计：对话式交互，适合即时咨询和探索性问题
