# 混凝土配合比成本优化说明

## 一、优化目标

在满足强度、坍落度、环境条件等性能约束的前提下，通过优化粉煤灰掺量、矿渣粉掺量、砂率、细骨料组合等参数，找到全生命周期成本最低的配合比方案。

---

## 二、约束条件

### 1. 性能约束（必须满足）

| 约束项 | 说明 |
|--------|------|
| 配制强度 | f_cu,0 = f_cu,k + 1.645 × σ，必须大于强度等级 |
| 胶凝材料用量 | 200 kg/m³ ≤ 总用量 ≤ 600 kg/m³ |
| 用水量 | 0 < 用水量 ≤ 250 kg/m³ |
| 粉煤灰 + 矿渣粉 | 总掺量 ≤ 50% |

### 2. 用户自定义约束（可调整范围）

- 粉煤灰掺量范围（默认 0~30%）
- 矿渣粉掺量范围（默认 0~20%）
- 砂率范围（默认 35~45%）
- 水胶比范围（如有需要）
- 网格搜索步长（默认 5%）

---

## 三、优化流程

### 步骤 1：计算水胶比

根据 JGJ 55-2011 规范，采用保罗米公式计算水胶比：

```
W/B = (α_a × f_b × γ_f) / (f_cu,0 + α_a × α_b × f_b × γ_f)
```

其中：
- α_a, α_b：回归系数（可从高级设置调整）
- f_b：水泥 28d 抗压强度
- γ_f：掺合料影响系数（根据粉煤灰掺量查表插值）

### 步骤 2：材料预处理

如果有多种同类材料，系统自动选择成本最低的一种：

| 材料类型 | 处理方式 |
|----------|----------|
| 粉煤灰 | 选择单价最低的品种（如 I 级粉煤灰） |
| 矿渣粉 | 选择单价最低的品种 |
| 减水剂 | 选择单价最低的品种 |
| 细骨料 | **保留多种，进行组合优化** |

### 步骤 3：细骨料组合优化

当存在多种细骨料（如粗砂 + 细砂 + 机制砂）时，系统生成多组掺配比例进行搜索：

**搜索策略：**
- 两种砂：按 2% 步长搜索（0%, 2%, 4%, ..., 100%），共 51 种组合
- 三种及以上：包括等比例、单选、两两混合等组合

**考虑因素：**
- 不同比例组合后的**细度模数**（影响骨料级配和密实度）
- 不同比例组合后的 **MB 值**（亚甲蓝值，反映泥粉含量）
- MB 值和细度模数共同影响**减水剂掺量**

### 步骤 4：网格搜索

对以下参数进行网格搜索：

| 参数 | 默认范围 | 默认步长 |
|------|----------|----------|
| 粉煤灰掺量 | 0~30% | 5% |
| 矿渣粉掺量 | 0~20% | 5% |
| 砂率 | 35~45% | 1% |
| 细骨料组合 | 动态生成 | — |

**每组参数组合的计算流程：**

1. **计算减水剂掺量**
   - 基准掺量（强度等级调整）
   - MB 值调整：每增加 0.1，掺量 +mbInfluence%
   - 细度模数调整：每减少 0.1，掺量 +finenessInfluence%

2. **计算减水率**
   - 基于减水剂掺量调整

3. **计算用水量**
   ```
   用水量 = 基准用水量 × (1 - 减水率)
   ```
   - 额外考虑粉煤灰需水量比的影响
   - 额外考虑矿渣粉流动度比的影响

4. **计算胶凝材料总量**
   ```
   胶凝材料 = 用水量 / 水胶比
   ```

5. **分配各胶凝材料用量**
   ```
   水泥 = 胶凝材料 × (1 - 粉煤灰% - 矿渣粉%)
   粉煤灰 = 胶凝材料 × 粉煤灰%
   矿渣粉 = 胶凝材料 × 矿渣粉%
   ```

6. **计算砂石用量**
   - 采用绝对体积法
   - 根据砂率分配砂和石的用量

7. **计算各项成本**
   ```
   各材料成本 = 用量(kg/m³) × 单价(元/吨) / 1000
   总成本 = Σ 各材料成本
   ```

### 步骤 5：验证与筛选

对每个计算结果进行约束验证，过滤不满足条件的方案。

### 步骤 6：选择最优方案

从所有有效方案中，选择**总成本最低**的方案作为最优方案。

---

## 四、成本构成

### 各材料对成本的影响

| 材料 | 成本影响方式 | 典型单价范围（元/吨） |
|------|-------------|---------------------|
| 水泥 | 用量大，单价高 | 400~600 |
| 粉煤灰 | 可替代部分水泥，降低胶材总量成本 | 100~300 |
| 矿渣粉 | 可替代部分水泥，降低胶材总量成本 | 150~350 |
| 细骨料 | 组合比例影响减水剂掺量，进而影响总成本 | 60~150 |
| 粗骨料 | 用量大，单价相对较低 | 50~100 |
| 减水剂 | 单价高，掺量受 MB 值和细度模数影响 | 3000~8000 |

### 关键成本权衡

1. **粉煤灰/矿渣粉 vs 减水剂**
   - 增加掺合料可减少水泥用量，降低材料成本
   - 但可能增加用水量和减水剂掺量，增加外加剂成本
   - 系统通过网格搜索找到最佳平衡点

2. **细骨料组合优化**
   - 不同比例的细骨料组合，其综合 MB 值和细度模数不同
   - MB 值高 → 需要更多减水剂 → 成本增加
   - 细度模数偏离目标值 → 需要更多减水剂或调整用水 → 成本增加
   - 系统搜索最优组合，平衡砂的成本和其对减水剂成本的影响

---

## 五、优化参数设置（高级设置）

用户可在"设置"页面调整以下参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| mbInfluence | MB值每增加0.1对减水剂掺量的影响（%） | 0.1% |
| finenessInfluence | 细度模数每减少0.1对减水剂掺量的影响（%） | 0.1% |
| 回归系数 α_a | 保罗米公式系数 | 0.53（碎石） |
| 回归系数 α_b | 保罗米公式系数 | 0.20（碎石） |
| 强度标准差 σ | 根据强度等级确定 | 自动查表 |

---

## 六、输出结果

优化完成后，系统输出：

1. **最优方案**：总成本最低的配合比
2. **备选方案**：前 5 个成本次优的方案供参考
3. **评估统计**：本次优化评估的有效方案总数

每个方案包含：
- 各材料用量（kg/m³）
- 各材料单价（元/吨）
- 各材料成本（元/m³）
- 总成本（元/m³）
- 水胶比、砂率等设计参数
- 选用的材料信息（名称、规格、厂家）

---

## 七、算法特点

- **网格搜索**：穷举式搜索，确保找到全局最优（或近似全局最优）
- **多因素耦合**：同时考虑强度、掺量、用水量、减水剂、细骨料组合的相互影响
- **灵活约束**：支持用户自定义掺量范围和水胶比限制
- **材料选择**：自动选择最优品种的粉煤灰、矿渣粉、减水剂
