
# 混凝土配合比智能设计 — 使用说明

---

## 一、功能概述

智能设计是本软件的核心 AI 功能模块，位于 **AI分析** 页面下。它利用 DeepSeek 大语言模型，通过自然语言对话的方式帮助工程师完成：

- **配合比设计**：根据强度等级、坍落度等要求，自动计算混凝土配合比
- **成本优化**：在给定材料范围内，通过网格搜索找到成本最低的材料组合
- **材料对比**：定量对比不同材料对配合比性能的影响
- **性能预测**：基于 XGBoost 模型，预测配合比的 28 天强度、坍落度、容重
- **规范审查**：对比国家/行业规范，审查配合比是否合规
- **数据智能分析**：上传配合比试验数据，进行参数诊断、材料影响分析、配合比参数分析、优化建议等结构化分析
- **销售报价**：快速生成客户报价单，包含材料成本明细和单方价格

## 三、两种工作模式

智能设计支持两种工作模式，系统会根据你的输入自动判断使用哪种模式。

### 3.1 设计模式（普通聊天模式）

**适用场景**：设计新配合比、优化成本、对比材料、预测性能、规范审查等。

**触发方式**：直接输入自然语言需求，例如：
- 「帮我设计 C30 配合比，坍落度 180mm」
- 「优化配合比成本」
- 「对比 P.O 42.5 和 P.O 42.5R 水泥对配合比的影响」
- 「预测这个配比的 28 天强度」

### 3.2 分析模式（数据驱动模式）

**适用场景**：你已经有了一批配合比试验数据（Excel 表格），想让 AI 帮你系统性地分析这些数据。

**触发方式**（三种）：
1. 上传一个 Excel 文件（.xlsx / .xls）
2. 在文本中输入包含「分析模式」关键词
3. 消息内容中同时包含「水胶比」和「强度」或「配合比」加数字

## 五、设计模式 — 完整操作流程

### 5.1 第一步：描述需求

在输入框中输入你的需求。以下是各场景推荐的提示词：

#### 场景A：设计新配合比

**推荐提示词**：
```
帮我设计C30配合比，坍落度180mm
```

也可以更详细：
```
帮我设计C50泵送混凝土配合比，坍落度200mm，要求使用P.O 42.5水泥
```

**AI 行为**：
1. AI 会先调用 `list_available_materials`（查询材料库），列出所有可用的材料
2. AI 会推荐一些材料供你选择
3. 你需要选择具体材料后才能进入计算

---

#### 场景B：成本优化

**推荐提示词**：
```
帮我优化C30配合比的成本，坍落度180mm，找到最便宜的材料组合
```

或更具体：
```
优化C40配合比成本，水泥只能用P.O 42.5，细骨料和粗骨料都可以选
```

**AI 行为**：
1. AI 先查询材料库
2. 列出可选材料供你确认
3. 确认后执行网格搜索（`optimize_mix_cost`），遍历所有材料组合，找到成本最低的方案
4. 展示最优方案 + 备选方案

---

#### 场景C：对比材料

**推荐提示词**：
```
帮我对比P.O 42.5和P.O 42.5R水泥对C30配合比的影响
```

也可以跨材料类型对比：
```
对比不同减水剂对C40配合比性能的影响
```

**AI 行为**：
1. AI 先查询材料库，找到对应的材料
2. 可能先做定性对比（免费）
3. ~~如果需要精确数据，调用 `compare_materials` 工具~~（v10.5.0 移除）
4. ~~展示对比表格：28d强度、成本、水胶比、砂率、胶材总量等~~（v10.5.0 移除）

---

#### 场景D：性能预测

**推荐提示词**：
```
我有一个C30配合比：水胶比0.45，水泥320kg，粉煤灰80kg，砂率42%，减水剂1.2%，预测28天强度能达到多少？
```

或输入已计算好的配合比：
```
预测我这条配合比的性能：水胶比0.42，水泥340，粉煤灰60，矿渣粉80，砂780，石1050，减水剂掺量1.0%
```

**AI 行为**：
1. 可能需要你指定具体的材料 ID（从材料库中选择）
2. 调用 `predict_performance` 工具，基于 XGBoost 模型预测
3. 返回预测的 28 天强度、坍落度、容重

---

#### 场景E：规范审查

**推荐提示词**：
```
帮我审查这条C30配合比是否符合规范：
强度等级C30，水胶比0.45，水泥用量320kg/m³，砂率42%，粉煤灰掺量20%，坍落度180mm，环境类别二a
```

**AI 行为**：
1. 调用 `check_compliance` 工具
2. 系统使用向量搜索检索规范知识库中的相关条款
3. 同时进行 16 项结构化规则匹配
4. AI 生成合规审查报告：合规项、不合规项（含严重程度、原因、修正建议）

---

### 5.2 第二步：选择材料

当 AI 列出了材料列表后，你会看到一个**材料选择器**，按四大类分组显示：

| 分组 | 包含的材料类型 | 显示的关键属性 |
|------|--------------|---------------|
| **水泥** | 水泥 | 28d强度、比表面积 |
| **掺合料** | 矿渣粉、粉煤灰、锂渣、复合粉 | 28d活性、需水量比、细度、流动度比 |
| **骨料** | 粗骨料、细骨料 | 细度模数、含泥量、规格 |
| **外加剂** | 减水剂 | 减水率、推荐掺量 |

每种材料会显示：名称、规格标签、关键属性、单价（元/吨）

**操作步骤**：
1. 勾选你想使用的材料（支持多选）
2. 可以使用「全选 / 取消全选」快速操作
3. 底部显示已选数量
4. 点击「确认选择」提交

### 5.3 第三步：等待 AI 计算

选择材料后，AI 会自动调用计算工具。你会看到一个加载动画（`ToolCallBubble`），显示当前正在执行的操作。

工具调用成功后，会显示对应的结果卡片。

## 六、结果卡片说明

AI 完成计算后，会根据调用的工具返回不同的结果卡片：

### 6.1 配合比设计结果卡片（MixDesignResultCard）

**调用工具**：`calculate_mix_design`

**卡片内容**：
- 材料用量表（水泥、粉煤灰、矿渣粉、锂渣、复合粉、细骨料、粗骨料、减水剂、水）
- 水胶比
- 砂率
- 容重（kg/m³）
- 配制强度（MPa）
- 每方成本（元/m³）
- 计算步骤（可展开查看详细计算过程）

**操作按钮**：「保存方案」— 将当前配合比保存到方案库

### 6.2 成本优化结果卡片（OptimizationResultCard）

**调用工具**：`optimize_mix_cost`

**卡片内容**：
- **最优方案**：材料组合、每方成本、水胶比、砂率
- **备选方案列表**（可展开）：多个成本较低的组合方案及其参数
- **评估总数**：总共评估了多少种材料组合
- 每方成本对比

### 6.3 材料对比结果卡片（MaterialCompareCard）⚠️ v10.5.0 移除

> v10.5.0 移除独立工具。如需对比材料，Agent 循环调用 `calculate_mix_design` 即可。

### 6.4 参数诊断结果卡片（DiagnosisResultCard）⚠️ v10.5.0 移除

> v10.5.0 移除独立工具与前端组件。智能解析模块（AIAnalysisPage 系列）已整体下线。

### 6.5 规范审查结果卡片（ComplianceResultCard）

**调用工具**：`check_compliance`

**卡片内容**：
- **合规状态标签**：合规 / 不合规
- **不合规项列表**：严重程度（严重/一般）、问题描述、原因、修正建议
- **合规项列表**：通过审查的条目

### 6.6 分析报告（AnalysisReport）

**触发方式**：在分析模式下，通过上传 Excel 数据获取

**卡片内容**（5 个可展开的折叠面板）：
1. **材料性能影响分析**：按强度等级分组，分析材料参数差异对性能的影响
2. **配合比参数影响分析**：量化分析水胶比、砂率、胶材用量等参数的影响
3. **最优配合比推荐**：基于数据规律预测全新的最优配合比
4. **参数调整建议**：按优先级排列的问题和改进方案
5. **进一步试验建议**：验证性试验 + 探索性试验 + 试验矩阵表

## 七、分析模式 — 完整操作流程

### 7.1 上传 Excel 文件

**支持的格式**：.xlsx / .xls

**数据要求**：
- Excel 文件应包含配合比数据，如：编号、强度等级、水胶比、各材料名称及用量、试验结果（R28强度、坍落度等）
- 材料名称应尽量与材料库中的名称一致，以便自动匹配

**操作步骤**：

1. 点击输入框旁的 `+` 按钮
2. 选择本地的 Excel 文件
3. 文件上传后，系统会：
   - 解析 Excel 中的配合比数据
   - 自动匹配材料名称到材料库
   - 如果所有材料都自动匹配成功 → 直接进入 AI 分析
   - 如果有材料未能自动匹配 → 进入材料选择流程

### 7.2 逐条补充材料（Excel 上传后）

当 Excel 中有材料名称无法与材料库自动对应时：

1. AI 会显示提示：「有 X 条配合比存在材料未自动匹配」
2. 系统会**逐条**让你为每条配合比选择缺失的材料
3. 每条配合比会显示：编号、强度等级、需要选择的材料类型
4. 从材料选择器中勾选对应的材料
5. 点击「确认选择」，系统自动跳转到下一条待补充的配合比
6. 全部补充完成后，自动触发 AI 分析

### 7.3 文本输入进入分析模式

如果你手动输入包含配合比数据的文本，系统会：

1. 检测到文本中有配合比数据（含水胶比 + 强度关键词）
2. 自动切换到分析模式
3. 尝试解析文本中的数据
4. 如果数据足以分析，直接调用 AI 分析

**示例文本**：
```
我有三条C30配合比数据：
配合比1：水胶比0.41，R28=45MPa，水泥320，粉煤灰80
配合比2：水胶比0.43，R28=42MPa，水泥310，粉煤灰70
配合比3：水胶比0.45，R28=39MPa，水泥300，粉煤灰60
帮我分析一下哪种方案最优
```

### 7.4 分析模式下的追问

分析报告生成后，你仍然可以继续追问：

**可追问的内容举例**：
- 「详细解释一下为什么配合比1的强度最高」
- 「比较配合比1和配合比2的成本差异」
- 「如果我要降低成本，应该优先调整哪个参数」
- 「根据分析结果，帮我设计一个C35的最优配合比」

系统会携带之前的分析上下文，进行针对性回答。

### 7.5 分析模式的五个分析维度

在「智能解析 → 数据处理」标签中，可以勾选需要 AI 分析的内容：

| 分析项 | 默认状态 | 说明 |
|--------|---------|------|
| 材料性能影响分析 | ✅ 开启 | 分析材料参数差异如何影响配合比性能 |
| 配合比参数影响分析 | ✅ 开启 | 量化分析配合比参数的影响程度 |
| 最优配合比设计 | ✅ 开启 | 预测生成全新的最优配合比 |
| 参数调整建议 | ✅ 开启 | 识别问题并给出调整方案 |
| 进一步试验建议 | ✅ 开启 | 设计验证性和探索性试验 |

如果你只关心某几项，可以在上传前取消不需要的分析项，以减少分析时间和 API 消耗。

## 八、AI 可调用的 7 个工具

AI 在对话过程中可以自主决定调用哪些工具。以下是所有工具的详细说明：

### 工具1：list_available_materials（查询材料库）

| 项目 | 说明 |
|------|------|
| **触发场景** | 任何涉及材料选择的操作，AI 会优先调用它 |
| **参数** | `type`（可选）：水泥 / 细骨料 / 粗骨料 / 粉煤灰 / 矿渣粉 / 锂渣 / 复合粉 / 减水剂 |
| **不填 type** | 返回所有材料 |
| **返回内容** | 材料列表（含 id、名称、类型、规格、价格、性能参数） |

### 工具2：calculate_mix_design（计算配合比）

| 项目 | 说明 |
|------|------|
| **触发场景** | 用户明确要求设计配合比，且所有必填参数已确认 |
| **必填参数** | `strength`（强度等级）、`slump`（坍落度 mm）、`cementId`（水泥 ID）、`sandIds`（细骨料 ID 列表）、`stoneIds`（粗骨料 ID 列表） |
| **可选参数** | flyAshId、slagId、lithiumSlagId、compositePowderId、superplasticizerId、各掺量、砂率、计算方法、目标容重、含气量、温度参数 |
| **温度参数** | 支持覆盖：回归系数αa/αb、强度标准差σ、MB值影响、细度模数影响、强度等级影响、基准细度模数 |

### 工具3：optimize_mix_cost（成本优化）

| 项目 | 说明 |
|------|------|
| **触发场景** | 用户要求找到最低成本方案 |
| **优化方式** | 网格搜索 — 遍历所有材料组合，找到成本最低且满足性能要求的方案 |
| **必填参数** | 同 calculate_mix_design |
| **特殊参数** | 候选材料 ID 列表（数组形式，支持多个备选）、各掺量范围、网格步长（默认5）、是否后台运行 |
| **计算量** | 较大（与候选材料数量呈指数关系），默认后台运行 |

### 工具4：~~compare_materials（材料对比）~~ ⚠️ v10.5.0 移除

> v10.5.0 移除独立工具。如需对比材料，Agent 循环调用 `calculate_mix_design` 即可。

### 工具5：~~run_parameter_diagnosis（参数诊断）~~ ⚠️ v10.5.0 移除

> v10.5.0 移除独立工具与前端组件。智能解析模块（AIAnalysisPage 系列）已整体下线。

### 工具6：check_compliance（规范审查）

| 项目 | 说明 |
|------|------|
| **触发场景** | 用户要求审查配合比是否合规 |
| **必填** | `strengthGrade`（强度等级）、`waterBinderRatio`（水胶比） |
| **可选** | 水泥用量、砂率、粉煤灰掺量、矿渣掺量、坍落度、环境类别、指定规范 ID |
| **审查流程** | 构建查询文本 → 向量化 → 语义搜索（Top-10）→ 16 项规则匹配 → 合并去重 → AI 生成报告 |

### 工具7：predict_performance（性能预测）

| 项目 | 说明 |
|------|------|
| **触发场景** | 用户询问配合比的预期性能 |
| **预测方式** | XGBoost 机器学习模型 |
| **必填参数** | `cementId`、`sandId`、`stoneId` |
| **可选参数** | 水胶比、各材料用量/掺量、温度(默认20℃)、湿度(默认95%)、龄期(默认28天) |
| **返回** | 预测 28d 强度、坍落度、容重、置信度 |

## 九、规范管理

在 AI 分析页面点击 **「规范管理」** 标签，可以管理国家标准知识库。

### 9.1 导入规范

1. 将国家标准 PDF 文件转换为 Markdown（.md）格式
2. 在规范管理页面，添加新的规范条目
3. 系统会自动：
   - 按章节标题拆分文本
   - 发送给 DeepSeek 进行结构化提取（4 线程并发）
   - 计算嵌入向量（16 条/批）
   - 保存为规范知识包

### 9.2 规范审查原理

当 AI 执行 `check_compliance` 时，整个流程为：

1. 根据配合比参数构建自然语言查询（如：「强度等级C30，水胶比0.45，水泥用量320kg/m³...」）
2. 用本地嵌入模型将查询文本向量化
3. 在规范知识库中做余弦相似度语义搜索，取 Top-10
4. 同时执行 16 项结构化规则匹配（水胶比、水泥用量、粉煤灰掺量、矿渣粉掺量、坍落度、砂率、含气量、强度等）
5. 合并两类结果（规则匹配优先）
6. 由 AI 生成最终审查报告

## 十、API 密钥配置

### 10.1 设置 API 密钥

智能设计依赖 DeepSeek API，使用前需要在系统设置中配置 API 密钥：

1. 进入软件的 **「设置」** 页面
2. 找到 **「DeepSeek API密钥」** 配置项
3. 填入你的 DeepSeek API Key（可在 [platform.deepseek.com](https://platform.deepseek.com) 获取）
4. 保存设置

如果未配置 API 密钥，智能设计功能会提示「DeepSeek API未配置」。

### 10.2 模型与参数

| 参数 | 值 |
|------|-----|
| 模型 | `deepseek-v4-flash` |
| 聊天最大 Token | 4096 |
| 分析最大 Token | 8192 |
| 思考模式 | 开启（thinking） |
| 请求超时 | 120 秒 |
| 工具调用最大轮次 | 5 轮 |
| 对话历史上限 | 20 条消息 |
| 上下文估算上限 | 约 120,000 tokens |

## 十一、对话管理

### 11.1 清空对话

点击输入框旁的 **清空按钮**（垃圾桶图标），可以：
- 清除当前对话的所有消息
- 重置材料选择状态
- 清除附件
- 退出分析模式
- 清除分析数据和分析结果
- 清空服务端的对话历史

### 11.2 对话上下文限制

- 对话历史最多保留 20 条消息（超过后自动截断）
- 总上下文估算不超过 120,000 tokens（约合 480,000 字符）
- 如果上下文估算超限，系统会提示清空对话后重试

### 11.3 分析模式退出

在分析模式下，输入框上方会显示蓝色 **「分析模式」** 标签，点击标签右侧的 `×` 按钮即可退出分析模式，回到普通设计模式。

## 十二、附件支持

### 12.1 支持的格式

| 格式 | 说明 |
|------|------|

- 可以点击标签上的关闭按钮移除附件
- 发送消息时会自动携带附件进入分析流程

## 十三、提示词技巧与最佳实践

### 13.1 设计配合比

**好的提示词**（信息完整）：
```
帮我设计C40泵送混凝土，坍落度200mm，我想要用P.O 42.5水泥，机制砂，
掺20%粉煤灰，帮我看看用什么材料比较合适
```

**不够好的提示词**（信息不足）：
```
设计一个配合比
```
→ AI 需要追问强度等级、坍落度等必填参数，增加交互轮次。

### 13.2 成本优化

```
帮我优化C30配合比成本，坍落度180mm。水泥从P.O 42.5和P.O 42.5R里选，
细骨料用机制砂或河砂都可以，粗骨料用5-31.5mm碎石。粉煤灰掺量10%-25%，
矿渣粉掺量0%-20%。
```

### 13.3 综合分析（含试验目的）

如果你有明确的试验目的，在分析模式的消息中写明，AI 会在所有分析维度中优先关注。例如：

```
这批数据是为了验证锂渣替代粉煤灰对C30配合比性能的影响，
请重点分析锂渣的掺量对强度和成本的影响，我需要在保证强度的前提下
尽可能降低成本。
```

## 十五、销售报价工作流

智能设计支持销售报价场景。销售可以直接在对话中输入：

```
帮我做一个 C35 抗渗混凝土报价
```

系统会先给出建议值，包括基础配合比、制造费、技术服务费、运输费、泵送费、13% 增值税和利润率。销售可以回复"按建议值生成"，也可以修改其中一项，例如：

```
制造费改 20，技术服务费按 25，利润率改 10%
```

报价统一为单方价格，单位为元/m³，不询问数量，不计算总金额。报价结果包含材料成本明细，并可导出 Excel。Excel 包含"内部核价"和"客户报价"两张表。

## 十六、常见错误与处理

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| DeepSeek API密钥未配置 | 系统设置中没有填写 API Key | 去设置页面配置 API 密钥 |
| DeepSeek API密钥无效 | API Key 错误或已过期 | 检查并更新 API Key（401 错误） |
| DeepSeek API请求频率超限 | 短时间内请求过多 | 稍等片刻再试（429 错误） |
| DeepSeek API请求超时 | 网络问题或服务繁忙 | 检查网络连接，稍后重试 |
| 对话上下文过大 | 对话历史过长 | 点击清空按钮重置对话 |
| 输入数据量过大 | 分析的配合比数据过多 | 减少配合比数量后重试 |
| 仅支持Excel和Markdown文件 | 上传了不支持的格式 | 将文件转换为 .xlsx 或 .md 格式 |
