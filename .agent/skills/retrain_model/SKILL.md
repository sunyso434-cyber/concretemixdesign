# retrain_model

## 功能
用最新试配记录数据重新训练 XGBoost 预测模型（28d 强度 / 容重 / 减水剂掺量），并自动保存模型版本。

## 触发条件
用户在对话中提到以下关键词时自动触发：
- "重新训练"
- "用试配数据训练"
- "更新模型"
- "训练模型"
- "重新训练模型"

## 执行流程

### 1. 确认用户意图
向用户确认是否要重新训练模型，提示：
- 将会使用所有试配记录（含基座数据 181 条）进行训练
- 训练过程可能需要 1-3 分钟
- 训练完成后会给出 RMSE / R² / MAE 等指标

### 2. 调用训练
通过 IPC `training:run` 启动训练：

```javascript
const result = await ipcRenderer.invoke('training:run', { nTrials: 50 })
```

### 3. 监听进度
通过 IPC `training:progress` 实时显示训练进度（TPE 调参 / 特征构建 / 模型保存等阶段）。

### 4. 返回结果
向用户展示训练结果：
- 模型版本号
- 各目标的训练指标（样本数 / RMSE / 树数量 / 最优参数）
- 汇总信息（总样本数 / 训练目标数 / 调参次数）

### 5. 错误处理
| 错误场景 | 处理方式 |
|----------|----------|
| 训练进行中 | 提示"训练进行中，请稍后"，阻止并发 |
| 试配数据不足 | 提示"试配数据不足 20 条，请录入更多试配记录" |
| 训练失败 | 提示具体错误原因，建议重试 |

## 示例对话

用户："帮我重新训练一下模型"

系统：
1. 确认：好的，我将用所有试配记录重新训练 XGBoost 模型（含 28d 强度 / 容重 / 减水剂掺量三个目标），预计需要 1-3 分钟，开始吗？
2. 用户确认后 → 调用 IPC `training:run`
3. 实时显示训练进度
4. 返回结果：训练完成！模型版本 v20260728_120000，强度 RMSE=3.21MPa，容重 RMSE=18.5kg/m³，减水剂掺量 RMSE=0.12%

用户："训练模型"

系统：同上流程
